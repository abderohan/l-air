# L'air — trouve les intrus !

8 affiches A4 à imprimer pour les enfants de 4 ans, sur le thème de l'air.
Chaque affiche contient **8 images** : 6 qui ont un lien avec l'air, et **2 intrus** à entourer.

- `affiches/affiche-1.png` … `affiche-8.png` : les 8 affiches (300 dpi, A4)
- `affiches/affiches-air.pdf` : toutes les affiches + la page corrigé en un seul PDF
- `affiches/corrige.png` : la page corrigé pour l'adulte
- `generate.py` : le script Python qui régénère tout (`python3 generate.py`)

## Les 8 affiches

| # | Titre | Les 2 intrus |
|---|-------|--------------|
| 1 | Le vent | la banane, la tortue |
| 2 | Ça vole ! | l'escargot, la chaise |
| 3 | On souffle ! | le gâteau, le caillou |
| 4 | Dehors, dehors ! | le nounours, la pomme |
| 5 | L'air et l'eau | le lapin, la banane |
| 6 | L'énergie du vent | la tortue, le gâteau |
| 7 | Tout s'envole ! | le poisson, le caillou |
| 8 | L'air partout | l'escargot, le nounours |

Le corrigé est aussi imprimé à l'envers en bas de chaque affiche.
